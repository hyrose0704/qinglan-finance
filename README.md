# 青览 · 个人理财工作台

行情观察、持仓估值、应急金与用款目标规划、配置参考、下跌情景计算。个人资金仅保存在当前浏览器，仓库中的资金均为演示数据。

## 网站

启用 GitHub Pages 后：<https://hyrose0704.github.io/qinglan-finance/>

仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。此后每次向 `main` 提交都会自动测试、构建和发布，Actions 页面可查看状态。

## 本地运行

需要 Node.js 24。

```sh
npm ci
npm run dev
```

访问终端显示的 `/qinglan-finance/` 地址。验证：`npm test`；构建：`npm run build`；生产预览：`npm run preview`。

## 数据与边界

- 浏览器每60秒尝试读取东方财富公开行情：国际现货黄金、纳斯达克100指数、美元指数及历史日线。供应商真实延迟未知，不是交易级行情。
- GitHub Actions 每15分钟尝试采集备用行情、美元人民币汇率与019442已公布净值。调度可能延迟，不构成实时承诺；静态备用数据保留原始时间。
- 连接失败时显示标注日期的快照，不把缺失值当成0。人民币黄金折算需两项报价15分钟内、相差不超过5分钟；否则使用手动价格。
- QDII净值按所属日展示，不等于盘中估值或实际赎回价格。新闻、实际利率和完整宏观事件流尚未接入，原因分析明确区分相关线索和待补证据。
- 资产只统计现金、黄金和指定基金；不是完整家庭资产负债表。配置是比较模板，压力测试只是显式假设，不保证收益或亏损上限。
- 个人数据不提交到GitHub、不发送给行情接口；浏览器导出档案请自行保存，勿提交仓库。

## 后续更新

继续修改本项目后，运行测试与构建，再推送 `main`。工作流会同步网站，无需手动复制构建文件。GitHub Pages、Actions及第三方行情服务可能有自身延迟或限制。
