# 青览 · 个人理财工作台

行情观察、持仓估值、应急金与用款目标规划、配置参考、下跌情景计算。个人档案默认保存在当前浏览器；主动使用 AI 助手时，问题、背景、最近对话和勾选的资金摘要会发送给 DeepSeek。仓库中的资金均为演示数据。

## 学习与资金规划

- 8节中文入门课：现金流、应急金、风险、分散、费用、QDII、黄金和执行复盘。每课包含个人/演示资金例子、随堂题、行动任务和原始延伸阅读。
- 复利与费用、QDII汇率、亏损回本三个可交互实验。所有收益率和跌幅均为假设，不是预测。
- 规划页先确认用款期限、收入稳定性和产品理解程度，再从选定模板收紧比例。资料缺失、现金预留不足、每月现金流为负或必要支出未填写时，不生成新增风险资产金额。
- 展示资金分层、候选金额、计算理由、现有与候选情景损失、下个月结余去向和投入前核对事项。已超出假设损失预算的现有持仓会占用新增风险余量。
- 阈值由本项目为学习比较设定，详见页面“模型规则与局限”和 `lib/allocation.ts`，不是监管标准或完整风险评级。现金候选栏尚未指定具体产品，不能视为货币/债券基金保本承诺。
- 资金档案、规划偏好、答题进度分别保存在当前浏览器。当前档案导出仅包含资金档案；偏好与学习进度暂不随导出迁移，也不跨设备同步。

## 已复用的查询能力

- 理财知识区支持本地关键词与相关概念检索，返回课程原文解释、课程入口和延伸阅读。它不调用大模型，不联网搜索，也不预测涨跌。
- 市场区展示美联储货币政策与美国劳工统计局CPI官方RSS的最新可用标题。每个来源仅保留一条标题及原文链接，分别标明发布时间和成功采集时间。
- 采集失败保留上次有效内容及原始时间；未成功的来源显示缺失。海外政策发布不是完整新闻流，不自动判断市场预期或行情因果。
- AI助手支持用户自己的DeepSeek Key进行文字问答，详见下一节。AI联网搜索、远程MCP及付费金融数据尚未接入。

## AI 连接、上下文与保存输入

- 在“AI 助手”页面输入自己的DeepSeek API Key。浏览器只请求固定的 `https://api.deepseek.com` 官方地址，禁用重定向，不经过项目服务器。连接时读取 `/models`，仅使用服务商返回的模型；不自动发起生成请求。
- 默认提供本地加密保存选项，使用PBKDF2-SHA256（250,000次）和AES-256-GCM，独立随机盐与nonce。解锁密码不保存；刷新后需解锁并重新验证。取消保存则Key仅在当前页面内存使用。解锁后的网页运行环境仍需可信，本地加密不防运行时恶意脚本。
- Key记录、资金档案、助手输入分开保存。Key不会被资金导出或“保存输入”复制。仓库和GitHub Actions不接收用户凭证，也不提供共享Key。
- 点击“发送给 DeepSeek”才会发起付费生成。请求提供问题、最多最近6轮对话和补充背景；可关闭“发送网站资金与规划摘要”，预览中可以核对资金、收支、还款、目标、成本、风险金额和规划条件。摘要每次读取当前网页档案与计算，弹窗中未提交的编辑不会读取；未知条件与演示数据显式标明。
- “保存输入”持久化补充背景、问题草稿、最近6轮对话、模型与摘要开关。刷新后自动恢复；离开助手页再返回也保留当前会话。资金档案和规划条件继续由原页面保存，助手输入不跨浏览器同步。
- 生成不启用联网、文件上传或工具调用，不把模型解释当作核实后的事实。每次输出最多2048 Token，不自动重试；截断、空回答、鉴权、余额、限流、网络错误分别提示。
- ChatGPT账号卡片只显示接入条件，不模拟登录成功。公开托管网页尚无获批OAuth客户端及后端；OpenAI的本机开放注册流程要求loopback回调，不能直接移植至GitHub Pages。参阅[官方网页接入说明](https://developers.openai.com/siwc/website)及[本机注册流程](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)。
- Key连接与生成的单元验证使用注入的假HTTP响应，不发送测试凭证。未经用户自行填写有效Key，无法验证真实账户权限、余额和生成结果。

## 本地运行

需要 Node.js 24。

```sh
npm ci
npm run dev
```

访问终端显示的 `/qinglan-finance/` 地址。验证：`npm test`；构建：`npm run build`；生产预览：`npm run preview`。

## 数据与边界

- 浏览器每60秒尝试读取东方财富公开行情：国际现货黄金、纳斯达克100指数、美元指数及历史日线。供应商真实延迟未知，不是交易级行情。
- GitHub Actions 每15分钟尝试采集备用行情、美元人民币汇率与019442已公布净值。调度可能延迟，不构成实时承诺；静态备用数据保留原始时间。
- 连接失败时显示标注日期的快照，不把缺失值当成0。人民币黄金折算需两项报价15分钟内、相差不超过5分钟；否则使用手动价格。
- QDII净值按所属日展示，不等于盘中估值或实际赎回价格。实际利率、通胀数值与完整宏观事件流尚未接入；原始政策标题供核对，原因分析明确区分相关线索和待补证据。
- 资产只统计现金、黄金和指定基金；不是完整家庭资产负债表。配置是比较模板，压力测试只是显式假设，不保证收益或亏损上限。
- 个人数据不提交到GitHub、不发送给行情接口。使用AI助手时，用户点击发送的内容按页面说明交给DeepSeek；助手的“保存输入”本身不触发网络调用。浏览器导出档案请自行保存，勿提交仓库。
