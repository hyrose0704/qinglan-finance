# 青览 · 个人理财工作台

行情观察、持仓估值、应急金与用款目标规划、配置参考、下跌情景计算。个人档案默认保存在当前浏览器；主动使用 AI 助手时，问题、背景、最近对话和勾选的资金摘要会发送给所选服务商。仓库中的资金均为演示数据。

## 学习与资金规划

- 8节中文入门课：现金流、应急金、风险、分散、费用、QDII、黄金和执行复盘。每课包含个人/演示资金例子、随堂题、行动任务和原始延伸阅读。
- 复利与费用、QDII汇率、亏损回本三个可交互实验。所有收益率和跌幅均为假设，不是预测。
- 规划页先确认用款期限、收入稳定性和产品理解程度，再从选定模板收紧比例。资料缺失、现金预留不足、每月现金流为负或必要支出未填写时，不生成新增风险资产金额。
- 展示资金分层、候选金额、计算理由、现有与候选情景损失、下个月结余去向和投入前核对事项。已超出假设损失预算的现有持仓会占用新增风险余量。
- 阈值由本项目为学习比较设定，详见页面“模型规则与局限”和 `lib/allocation.ts`，不是监管标准或完整风险评级。现金候选栏尚未指定具体产品，不能视为货币/债券基金保本承诺。
- 资金档案、规划偏好、答题进度分别保存在当前浏览器。当前档案导出仅包含资金档案；偏好与学习进度暂不随导出迁移，也不跨设备同步。
- 新建个人档案时，数值输入框为空，灰色文字仅为填写示例。保存时空白数值按0计算，并记录实际填写过的字段；再次编辑时未填写项仍为空，明确填写的0正常回填。已有个人档案保留原数值，部分导入数据不会补入演示金额。应急月数、必要支出或持仓价格缺失时，提示补齐条件，暂停新增风险资产安排。

## 已复用的查询能力

- 理财知识区支持本地关键词与相关概念检索，返回课程原文解释、课程入口和延伸阅读。它不调用大模型，不联网搜索，也不预测涨跌。
- 市场区展示美联储货币政策与美国劳工统计局CPI官方RSS的最新可用标题。每个来源仅保留一条标题及原文链接，分别标明发布时间和成功采集时间。
- 采集失败保留上次有效内容及原始时间；未成功的来源显示缺失。海外政策发布不是完整新闻流，不自动判断市场预期或行情因果。
- AI助手支持自己的DeepSeek Key，以及通过本机程序进行官方ChatGPT账号套餐授权。AI联网搜索、远程MCP及付费金融数据尚未接入。

## AI 连接、上下文与保存输入

- “个人中心”集中管理AI连接；“AI 助手”也保留连接入口，可以选择DeepSeek或ChatGPT本机账号。同一页面内切换栏目保留已解锁连接，刷新后的恢复方式见下文。
- DeepSeek：输入自己的API Key。浏览器只请求固定的 `https://api.deepseek.com` 官方地址，禁用重定向，不经过项目服务器。连接时读取 `/models`，仅使用服务商返回的模型；不自动发起生成请求。
- 默认提供本地加密保存选项，使用PBKDF2-SHA256（250,000次）和AES-256-GCM，独立随机盐与nonce。解锁密码不保存；刷新后需解锁并重新验证。取消保存则Key仅在当前页面内存使用。解锁后的网页运行环境仍需可信，本地加密不防运行时恶意脚本。
- Key记录、资金档案、助手输入分开保存。Key不会被资金导出或“保存输入”复制。仓库和GitHub Actions不接收用户凭证，也不提供共享Key。
- 点击发送才会使用所选服务的API余额或套餐额度。请求提供问题、最多最近6轮对话和补充背景；可关闭“发送网站资金与规划摘要”，预览中可以核对资金、收支、还款、目标、成本、风险金额和规划条件。摘要每次读取当前网页档案与计算，弹窗中未提交的编辑不会读取；未填写但按0计算的字段、未知条件和演示数据显式标明。
- “保存输入”持久化补充背景、问题草稿、最近6轮对话、所选服务、模型与摘要开关。刷新后自动恢复；离开助手页再返回也保留当前会话。资金档案和规划条件继续由原页面保存，助手输入不跨浏览器同步。切换服务会继续使用当前对话，发送前请核对摘要和已有聊天内容。
- 生成不启用联网、文件上传、工具调用或本机文件访问，不把模型解释当作核实后的事实。不自动重试；截断、空回答、鉴权、余额、限流、网络错误分别提示。DeepSeek每次输出最多2048 Token；ChatGPT套餐接口按官方支持的参数发送，以完整结束事件确认回答成功。
- 自动验证使用注入的假HTTP响应和临时加密夹具，不发送真实凭证或消耗套餐。用户完成真实账号授权前，无法验证其模型权限、套餐额度和实际生成结果。

## ChatGPT / Pro 本机连接

需要在使用网站的电脑上安装Node.js 24并下载本项目。首次启动：

```sh
npm ci
npm run build
npm run local-assistant
```

1. 打开网站“个人中心”，点击“连接本机助手”。本机确认窗口会显示请求来源，用户点击“允许本次连接”后才允许该网页使用本机AI接口。
2. 点击“Continue with ChatGPT”，在OpenAI官方页面完成登录及套餐使用授权。程序不会读取或复制Codex现有登录文件，也不会要求把密码或OpenAI令牌填入网站。
3. 选择官方返回的账号和模型，在AI助手中选择“ChatGPT 本机账号”再发送问题。可保留多个账号的显示信息，重新授权、切换账号或退出。模型列表成功不等于生成成功；实际回答完整结束后才记录验证时间。
4. 以后使用时先运行 `npm run local-assistant`。网页刷新后需重新确认本机连接；符合条件且仍有效的本机账号凭证可继续使用，过期或退出后再登录。关闭终端会停止本机服务；未设置开机启动。

本机地址：<http://127.0.0.1:48791/>。若浏览器阻止GitHub Pages访问loopback，或未允许本地网络连接，打开本机版本 <http://127.0.0.1:48791/qinglan-finance/>；不同来源的资金档案和助手输入各自保存在浏览器中，可通过资产导入导出迁移，凭证不随导出迁移。

- 使用官方[本机动态注册与登录](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)、[模型及推理](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)、[账号保存和刷新](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions)流程。PKCE、state、nonce及签名验证保护授权；只使用公共 `/v1/models`、`/v1/responses` 接口，不使用ChatGPT私有网页接口。
- 本机服务仅监听 `127.0.0.1:48791`，限制Host和网站来源。网页连接许可仅在内存中保存，绑定来源并在8小时后失效；账号访问令牌和刷新令牌不返回网页。浏览器只保存上次账号显示信息，不将其视为已登录证明。
- 账号文件保存在仓库之外：Windows为 `%LOCALAPPDATA%/QinglanFinance/local-assistant/accounts.json`，使用当前Windows用户的DPAPI加密。其他系统使用仅当前用户可读写的文件权限。退出会尝试官方撤销并清除本机凭证；撤销未确认时会明确提示。
- Pro不等于可使用所有模型或无限调用，账号资格、可用模型、用量和共享授权以OpenAI官方实际结果为准。GitHub Pages本身不保存OpenAI凭证，也不提供面向其他设备的共享代理。纯远程网页账号登录仍需要[官方网页接入条件](https://developers.openai.com/siwc/website)。

## 数据与边界

- 浏览器每60秒尝试读取东方财富公开行情：国际现货黄金、纳斯达克100指数、美元指数及历史日线。供应商真实延迟未知，不是交易级行情。
- GitHub Actions 每15分钟尝试采集备用行情、美元人民币汇率与019442已公布净值。调度可能延迟，不构成实时承诺；静态备用数据保留原始时间。
- 连接失败时显示标注日期的快照，不把缺失值当成0。人民币黄金折算需两项报价15分钟内、相差不超过5分钟；否则使用手动价格。
- QDII净值按所属日展示，不等于盘中估值或实际赎回价格。实际利率、通胀数值与完整宏观事件流尚未接入；原始政策标题供核对，原因分析明确区分相关线索和待补证据。
- 资产只统计现金、黄金和指定基金；不是完整家庭资产负债表。配置是比较模板，压力测试只是显式假设，不保证收益或亏损上限。
- 个人数据不提交到GitHub、不发送给行情接口。使用AI助手时，用户点击发送的内容按页面说明交给所选的DeepSeek或OpenAI；助手的“保存输入”本身不触发网络调用。浏览器导出档案请自行保存，勿提交仓库。
